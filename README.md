# Real MySQL 8.0 스터디

## 📖 스터디 개요

* **도서** : Real MySQL 8.0 1
* **기간** : 2026.06 ~ 2026.08
* **시간** : 매주 목요일 11:00 ~ 13:00 (유동적으로 조율가능)

  * 예상 소요 시간 : 1시간
  * 최대 소요 시간 : 2시간

---

## 🚀 진행 방식

* 매주 정해진 학습 범위를 사전에 학습합니다.
* 학습 범위와 관련된 주제를 선정하여 화요일 23:59까지 블로그 게시글을 작성합니다.
* 화요일 23:59까지 학습 범위와 관련된 토론 주제를 GitHub Repository의 Issue에 등록합니다.
* 미팅 시간에 작성한 주제에 대해 발표하고 내용을 공유합니다.
* 발표자는 스터디 당일 룰렛으로 선정합니다. (발표 1~2인 예상, 상황따라 발표자 수 다를수도 있음)
* 목요일 미팅 전까지 다른 멤버의 토론 주제에 대해 조사한 후, 미팅 시간에 함께 토론합니다.
* 스터디 진행 현황 및 자료는 GitHub Repository를 통해 관리합니다.
